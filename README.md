# 🍽️ TasteNest — Food Ordering & Fine Dining Website

TasteNest is a modern, responsive web application built with React and Tailwind CSS. It features artisanal coffee houses, gourmet culinary dishes, table reservations, interactive food menus, reviews, and mobile app ordering banners with smooth micro-animations.

## 🚀 Features

- **Hero & Table Reservations**: Cinematic visuals and interactive booking CTAs.
- **Story & Specialties**: Highlighting culinary chefs, organic micro-lot coffee, and recipes.
- **Why Choose Us**: Feature highlights with 3D floating icons and ambient glassmorphic cards.
- **Working Hours & Schedule**: Service schedules with live status indicators.
- **Animated Reviews & Statistics**: Interactive animated count-up statistics and guest testimonials.
- **Food Menu**: Gourmet dishes with details, pricing, and "Order Now" actions.
- **Mobile App Download Banner**: Full-width ordering banner with store badges.
- **Newsletter Subscription**: Animated newsletter signup form.
- **Modern Animations**: High performance CSS & JS animations with scroll reveal, moving title marquee, and micro-interactions.

## 🛠️ Tech Stack

- **Framework**: React 19
- **Build Tool**: Vite
- **Styling**: Tailwind CSS & Vanilla CSS Design System
- **Fonts**: Playfair Display & Inter

## 💻 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/Sushanth666/TasteNest-Food-Ordering-Website.git
cd TasteNest-Food-Ordering-Website
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run development server
```bash
npm run dev
```

### 4. Build for production
```bash
npm run build
```
